# DB·MCP 작업 현황

기준일 2026-10-21. LLM2·LLM3 구현은 보류합니다.

| 순서 | 작업 | 상태 |
|---|---|---|
| 1~3 | 범위·도구 계약·데이터 매핑·DB 설계 | 완료, 실제 Backend 변경 반영 |
| 4 | PostgreSQL16·pgvector·마이그레이션 | 로컬 완료, Backend V1/V2와 SQL 공존 검증 |
| 5 | JASC·SDR·AMM·근거 적재 | 전체 corpus 적재 및 재실행 중복 방지 검증 |
| 6 | 인증·접수 범위·버전·스냅샷 | 서버 구현 완료, Backend 전달 연결은 남음 |
| 7~10 | R01/R02/R03/R05와 HTTP MCP | 네 도구 구현 및 실제 SDK 호출 검증 |
| 11 | 로컬 다국어 임베딩·pgvector 검색 | 31,678개 벡터 구축, 한국어/영어 검색→R05 검증 |
| 12 | 검토·재현 절차·저장소 인계 | 자동 테스트·실행/통합 문서 제공 |

다음 팀 통합 순서는 ① Backend Flyway에 SQL 통합 및 pgvector 이미지 준비 ② 검증된 서비스 코드 매핑 확정 ③ Backend 실행 컨텍스트·위임 토큰 전달 ④ MCP 클라이언트 연결 ⑤ 배정 직전 근거 검증과 업무 시나리오 실행입니다. [구체적 연결 항목](../integration/backend/README.md)을 참고합니다.

로컬 DB·MCP 구성 완료와 팀 애플리케이션 전체 연결 완료를 구분합니다. 현재 검색 품질·진단 정확도 평가, 실제 매뉴얼 본문, business-mcp, RabbitMQ 실행기와 LLM 노드는 구현 범위 밖입니다.
